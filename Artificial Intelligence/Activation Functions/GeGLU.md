#### 게이트란?
- 어떤 정보가 뉴런을 통과할지 말지 "결정"하는 장치
- 딥러닝에서는 이것을 보통 수학적으로 "곱셈"연산으로 구현함
	- 출력 = 정보 x 게이트값
	- 여기서 "게이트 값"은 보통 0~1 사이의 실수 값으로,
		- 1이면 정보가 그대로 통과 (열림)
		- 0이면 정보가 완전히 차단 (닫힘)
		- 0~1이면 일부만 통과 (부분 열림)

- 따라서 GeGLU는 다음과 같이 작동함
	- GeGLU(x) = (정보 경로) x (게이트 경로)
		- 정보 경로: $xW_1$
		- 게이트 경로: GeLU($xW_2$)
		- 중요도가 높은 입력은 **게이트 값 ≈ 1** → 거의 전부 통과
		- 중요하지 않은 입력은 **게이트 값 ≈ 0** → 거의 차단
	- $W_1$​은 "무엇을 전달할까?"를 배우고,
	- $W_2$​는 "얼마나 중요하게 봐야 할까?"를 배우는 것

- 예를 들어:
	- $xW_1$: 문맥적으로 ‘의미 있는’ 정보를 표현
	- $xW_2$​: 문맥적으로 ‘필요한지 아닌지’ 판단하는 게이트 역할
